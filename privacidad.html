Responsable y contacto

MiniYT es una aplicación en desarrollo. Para consultas relacionadas con privacidad y protección de datos, escribe a miniytandroid@gmail.com.

Conexión opcional con Google Drive

Cuando decides conectar Google Drive, Google gestiona la selección de la cuenta y la autorización. MiniYT solicita el permiso https://www.googleapis.com/auth/drive.file, limitado a los archivos creados o autorizados específicamente para la aplicación.

Para ofrecer la navegación y gestión de esos archivos, MiniYT puede consultar sus identificadores, nombres, tipos, metadatos y contenido cuando una operación solicitada por el usuario lo requiera. También puede crear carpetas y subir o descargar archivos dentro del alcance autorizado.

Finalidad del acceso

El acceso a Drive se utiliza para ejecutar las acciones que solicitas en la aplicación, como explorar archivos disponibles para MiniYT, seleccionar destinos y transferir archivos. No se utiliza para publicidad personalizada ni para vender datos de Google Drive.

Almacenamiento y terceros

Los archivos que eliges guardar en Google Drive se almacenan en tu cuenta de Google conforme a sus condiciones. MiniYT se comunica con las API de Google para ejecutar las operaciones autorizadas. Para obtener o gestionar contenido multimedia, la aplicación también puede comunicarse con los servicios de origen correspondientes.

La aplicación puede conservar localmente preferencias y datos necesarios para su funcionamiento, como información de sesión o destinos seleccionados. La política se revisará si se incorporan servicios de analítica, cuentas propias, sincronización adicional u otras funciones que impliquen nuevos tratamientos.

Control de acceso y revocación

Puedes cambiar de cuenta desde MiniYT y revocar el acceso concedido a la aplicación desde la configuración de seguridad de tu cuenta de Google: Conexiones con terceros de Google. La revocación impide nuevas operaciones autorizadas, pero no elimina automáticamente los archivos que hayas guardado en tu Drive.

Consultas

Para preguntas sobre los datos tratados por MiniYT, contacta con miniytandroid@gmail.com.
